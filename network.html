Connection modes are choices with different purposes and limits. The prototype offers Normal, Tor, and Offline sessions; I2P is a planned addition.

TOR MODE

A different route.
The same responsibility.

KALQOR’s prototype routes supported connections through the local Tor service and uses firewall restrictions to block other external traffic.

Installed applications can still use their saved accounts, cookies, files, and identifiers. Routing traffic does not make those identities disappear.

Learn about Tor ↗

Understand the boundaries

  • Tor transports TCP; ordinary UDP and many real-time apps will not work through this mode.
  • External IPv6 is blocked in the restricted prototype.
  • Login waits for a Tor readiness check; failure retains restrictions.
  • Full logout is required before selecting another mode.
  • This is not a claim of Tails-level anonymity.

PLANNED INTEGRATION

A network within
the network.

I2P is being explored as another connection option for KALQOR.

I2P focuses on communication and services inside its own network. Proposed integration would help users configure compatible applications to access I2P destinations.

Ordinary internet access requires an outproxy and has different availability and trust considerations. I2P is not a drop-in route for every installed app or every internet protocol.

Read the official I2P overview ↗
Not shipped yet: no full-system I2P routing, isolation, or leak-prevention guarantee is being made.

Privacy starts with clear expectations.

Does this website change my network mode?

No. The website explains the modes. You select an OS session at the KALQOR login screen.

Can I switch without logging out?

The intended workflow requires a full logout and a new mode selection at login. A network guard is designed to apply before login and again on logout.

Are my applications and files separate between modes?

Not automatically. The same account retains its profiles and data. Separate identity and application-profile isolation are not promised.

Does Tor mode guarantee every app works?

No. Unsupported protocols are blocked, and applications may still identify you through their own data or login sessions.
