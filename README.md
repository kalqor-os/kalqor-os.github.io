# KALQOR OS website

Professional static website. Developer: Balaji Sangana.

Deploy the contents of dist/ to any static host. Entry point: index.html. Five pages: overview, download status, documentation, network modes, and project/roadmap. No dependencies or compilation needed. Theme preference is browser-local. There is no analytics or data-collection backend.

I2P is intentionally marked planned; do not present it as implemented full-system routing without corresponding OS changes and validation. The download page intentionally has no fabricated ISO URL or checksum. Add verified release assets after testing and publication. Illustrative mode controls do not affect visitor networking. Keep the archive-key fingerprint current if a real key rotation occurs.

To preview locally, serve dist/ with a static HTTP server (for example python3 -m http.server 8000 --directory dist). Source files use relative links and can be hosted on a domain or subdirectory. No domain purchase, DNS setup, or public access change was performed.
