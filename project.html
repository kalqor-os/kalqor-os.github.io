ABOUT KALQOR

A desktop project.
A considered direction.

KALQOR OS is an independent Debian-based Linux project developed by Balaji Sangana, centered on a lightweight desktop and understandable network choices.

THE FOUNDATION

Build on what works.
Make the choices clear.

KALQOR combines Debian packages, the LXQt desktop, its own artwork, and a signed update channel. Development currently focuses on making the live image, installer, and connection modes reproducible and testable.

The project is in development preview. Features are described by their current status rather than presented as a finished release.

Debian, LXQt, Tor, and I2P are independent upstream projects. Their mention does not imply endorsement or affiliation.

THE ROADMAP

Where we are.
Where we’re going.

DEVELOPED & VM-TESTED

Identity and updates

Custom branding, login artwork, boot artwork, and a signed APT repository with KALQOR release and branding packages.

BUILT · VALIDATION NEXT

The first test ISO

Live-build image with LXQt and portable network-mode configuration. Separate-VM boot, installer, and mode testing remain necessary.

PLANNED

I2P integration

Define supported applications, proxy setup, isolation, and clear traffic boundaries before offering a new connection option.

EXPLORATORY

Explain & Undo

Investigate guided repairs that describe proposed changes and recovery options. Not currently shipped.

PARTICIPATE

Useful feedback
moves the project forward.

Clear test results are more valuable than broad promises. Help document what works, what fails, and what a new user needs to understand.

Ways to contribute

  • Test a published preview in an isolated virtual machine.
  • Report reproducible update-repository problems.
  • Suggest documentation improvements.
  • Share accessibility and desktop usability feedback.

Never include private signing keys, passwords, or access tokens in reports.
