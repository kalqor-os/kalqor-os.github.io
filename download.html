TEST BEFORE YOU INSTALL

Begin in a virtual machine.

The current development target is an amd64 desktop. Hardware minimums have not been established by a full compatibility test programme.

  • Suggested test VM: 4 GB RAM and 2 CPU cores.
  • Use a separate, empty virtual disk of at least 25 GB.
  • Check boot, login, graphics, sound, and each network mode.
  • Test installation separately from the live session.

These are development test settings, not verified minimum hardware requirements.

WHEN A PUBLIC BUILD IS READY

A download is only the beginning.

01

Verify the image.

Compare its SHA-256 checksum with the published release information and follow the signature instructions.

02

Try the live session.

Start with a VM or spare machine. Validate your hardware and understand the network choices.

03

Install deliberately.

Back up your files. Read the release’s known issues before selecting a disk or partition.

Already running the development system?

If the KALQOR repository has been configured and its signing key verified, update through APT:

sudo apt update
sudo apt upgrade

Debian supplies base-system packages. KALQOR supplies its own release and branding packages. An APT update does not install an entirely new operating system.
